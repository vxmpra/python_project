# Garden Web Service

Сервис помогает садоводам ухаживать за растениями, предоставляя рекомендации по поливу на основе города растения и советы по защите от вредителей и болезней. Подходит как новичкам, так и опытным огородникам, желающим оптимизировать уход за своим садом.

Ссылка на рабочий проект: [https://vxmpra.pythonanywhere.com](https://vxmpra.pythonanywhere.com)

## Стек технологий
Backend: Python 3.11.7, Django 5.2.10  
External API: OpenWeatherMap API (прогноз погоды для расчёта полива растений)  
Frontend: Bootstrap 5 (UI/UX), HTML5  
Geolocation & Maps: leaflet (отображение города, в котором находится растение)  
Data Processing:  
* requests — работа с внешним API для получения погоды   
* python-dotenv — безопасное хранение API ключей и секретов проекта

## Интерфейс и возможности
**1. Главная страница проекта**

Пользователь видит общее количество растений в базе, каталог всех растений с сортировкой по категориям. Доступны кнопки регистрации и входа.

**2. Мой сад**

Личный кабинет пользователя («Мой сад») отображает все растения пользователя, сгруппированные по категориям с указанием количества экземпляров, с возможностью добавления новых растений через кнопку «Добавить растение +»; для каждого растения есть кнопка «Подробнее», открывающая рекомендации по поливу и защите от вредителей.

<img width="1835" height="917" alt="image" src="https://github.com/user-attachments/assets/387fcbc2-59a6-4904-b7f8-b2574a77851e" />

**3. Добавить растение**

На странице «Добавить растение» пользователь выбирает название растения из каталога и указывает город, где оно растёт, чтобы добавить его в свой сад. При вводе города выполняется проверка через API OpenWeatherMap: если город не найден, выводится сообщение об ошибке.

<img width="1854" height="911" alt="image" src="https://github.com/user-attachments/assets/c8703bdc-8ebd-4746-8aa6-0ea61fa9c950" />

**4. Детали растения**

На странице «Детали растения» отображается информация о выбранном растении, включая его описание и историю полива. Также есть две кнопки: «Посмотреть рекомендации по поливу», которая показывает советы по поливу растения (по погоде и осадкам), и «Посмотреть рекомендации по защите», которая перенаправляет на страницу с рекомендациями по защите от вредителей и болезней из базы данных.

<img width="1854" height="907" alt="image" src="https://github.com/user-attachments/assets/6ab02729-8cd2-414d-acd7-9c50b11efe57" />

**5. Рекомендации по поливу**

На странице «Рекомендации по поливу» отображаются погодные данные на текущий день из OpenWeatherMap, включая температуру, влажность, осадки и сезон. Для наглядности рядом показывается интерактивная карта Leaflet с городом растения. Также доступен 5-дневный прогноз полива в виде интерактивного графика, где рекомендации по каждому дню показываются при наведении.

## Как запустить проект локально
Если вы хотите развернуть проект на своем компьютере, следуйте инструкции:
#### 1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vxmpra/python_project.git
   cd python_project
   ```
####  2. Создайте и активируйте виртуальное окружение:

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Mac/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

#### 3. Установите зависимости:
```bash
pip install -r requirements.txt
```

#### 4. Настройте переменные окружения:
1. Создайте файл `.env` в корне проекта
2. Добавьте ваш API-ключ (получить можно на [OpenWeatherMap](https://openweathermap.org/api)):

```
OPENWEATHER_API_KEY = ваш ключ от OpenWeatherMap
SECRET_KEY = ваша секретная строка django
DEBUG=True
```

Для генерации нового безопасного ключа (SECRET_KEY) выполните следующую команду в терминале:
```bash
python -c 'from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())'
```

#### 5. Выполните миграции:
```bash
python manage.py migrate
```

#### 6. Наполните базу данных:
```bash
python manage.py fill_plants #загружает каталог растений
```

#### 7. Запустите сервер:
```bash
python manage.py runserver
```

#### 8. Откройте проект в браузере:
Откройте в браузере: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
